# Sistema de Cadastro de Colaboradores

Projeto desenvolvido para a disciplina **Desenvolvimento de Sistemas II**.  
O objetivo é criar um sistema simples de cadastro para novos colaboradores das **Lojas Brincos e Companhia**, utilizando **HTML** e **PHP**.

## 🚀 Funcionalidades
- Formulário em HTML para coleta de dados:
  - Nome completo
  - Idade
  - Profissão
  - Salário pretendido
  - Experiência anterior
- Processamento em PHP via método **POST**
- Exibição dos dados cadastrados em uma página de confirmação
- Mensagem personalizada utilizando nome, profissão e experiência
- Link para retornar ao formulário.
